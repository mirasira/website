How Cryptographic Hashes Work

The Problem: Positional Prime Hash

This is a linear hash function. It uses basic addition and multiplication, then finds the remainder divided by 11. Why it fails: Because it is mathematically reversible, an attacker can easily work backward from the hash to find a valid password.

The Fix: Toy-SHA-8

To prevent attackers from working backward, real algorithms use non-linear bitwise operations. Toy-SHA-8 mimics SHA-256 on a tiny 8-bit scale.

  • XOR (Exclusive OR): Shreds information by flipping bits based on other bits.
  • Bit Shift: Rotates the binary 1s and 0s out of their original positions.
  • Modulo 256: Forces the output to be exactly 8 bits (a number from 0 to 255).
